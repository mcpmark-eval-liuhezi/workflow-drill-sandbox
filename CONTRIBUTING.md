# Contributing to this repo

Thanks for your interest in contributing! Follow these steps to get your changes merged.

## How to contribute

- Open an issue first to discuss and track what you want to add or fix.
- Create a short, descriptive branch name (e.g. `fix-login-error`, `add-contributing-guide`).
- Make your changes and keep pull requests focused on one idea each.
- Include a clear description in the pull request and link the related issue.
- Request a review from a maintainer before targeting the default branch.

## Getting help

If you're stuck, ask in the issue or comment on the pull request — we're happy to nudge you along.
